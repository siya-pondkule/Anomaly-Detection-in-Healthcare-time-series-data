Anomalies in ICU Monitoring
1. Vital Signs Anomalies
Heart rate (HR): tachycardia, bradycardia, sudden fluctuations.
Blood pressure (BP): hypotension, hypertension spikes, abnormal variability.
Respiratory rate (RR): apnea events (no breaths detected), tachypnea, erratic patterns.
Oxygen saturation (SpO₂): hypoxemia, sudden desaturations, sensor dropouts.
Temperature: hyperpyrexia, hypothermi.
